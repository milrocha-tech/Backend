Estudos de Back-End com PHP

Este repositório reúne todos os códigos, exercícios e projetos práticos desenvolvidos durante as aulas de desenvolvimento Back-End.

 Tópicos Aprendidos
Sintaxe básica do PHP: Variáveis, operadores e estruturas condicionais (if, else).
Estruturas de repetição: Laços de repetição (for, while, foreach).
Formulários e Requisições HTTP: Envio e manipulação de dados via métodos GET e POST.
